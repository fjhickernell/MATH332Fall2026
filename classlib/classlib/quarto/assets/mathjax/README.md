# MathJax runtime

Pinned MathJax 3.2.2 `es5/tex-svg-full.js`, distributed under the included
Apache 2.0 license. Source: https://cdn.jsdelivr.net/npm/mathjax@3.2.2/es5/tex-svg-full.js

Serve this complete TeX-to-SVG bundle with slide resources so equation
rendering does not depend on an external CDN during a lecture or preview.
The complete bundle includes the TeX extensions used by the shared macros.
