\[ \begin{aligned} x+y&=6 &&\text{sensor 1}\\ 2x-y&=3 &&\text{sensor 2}\\ 3x&=9 &&\text{sensor 3} \end{aligned} \]

All three constraints agree

Compute responsibly

  • Almost parallel, almost unknowable
  • Exact mathematics, finite arithmetic
  • Can we trust the answer?

Almost parallel, almost unknowable

Nearly dependent measurements contain little independent information

A tiny change in the data can cause a large change in the solution

This is ill-conditioning

Exact mathematics, finite arithmetic

Computers store only a finite set of numbers

\[ 0.1+0.2\ne0.3 \qquad \text{in ordinary binary floating-point arithmetic} \]

Usually the tiny error is harmless

But a sensitive problem or unstable algorithm can amplify small errors

A mathematically correct method can still produce an unreliable numerical answer.
